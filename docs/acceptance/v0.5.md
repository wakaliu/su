# v0.5 验收清单（Rules + @上下文 + 轻量检索）

验收人：________  日期：________

目标：在不引入向量库 / MCP / 无人值守终端的前提下，补齐对照 Cursor 的上下文与 Rules 能力。

前置：v0.4 / v0.4.1 已勾选通过。

## Rules

- [ ] 支持工作区 `.su/rules/**/*.md`（或约定目录）注入 system / 开发者提示
- [ ] 设置项可开关 Rules；无文件时不报错
- [ ] 规则变更后下一轮对话生效（无需重启 IDE）
- [ ] 文档说明 Rules 写法与优先级（工作区 > 用户默认若有）

## @ 上下文

- [ ] 输入 `@` 可选择：当前文件 / 工作区文件 / 符号（或近似）/ 选区
- [ ] 选中项以 chip 或引用块进入本轮消息，替代仅「附带选区」勾选作为主路径
- [ ] 勾选选区仍可用（兼容），与 `@` 引用不冲突
- [ ] 大文件有截断策略（有上限，UI 有提示）

## 轻量检索

- [ ] 打开文件 + 近邻路径（同目录 / 同 git 改动可选）可进入上下文
- [ ] 基于 ripgrep（或宿主搜索 API）的关键词检索，结果可预览并 `@` 引用
- [ ] **不做**向量库 / 全库 embedding
- [ ] 检索失败时降级为「仅打开文件 + 用户粘贴」，有明确提示

## Apply / Diff

- [ ] 单块代码「应用到当前文件」可用（v0.4.1 已有则回归）
- [ ] Agent 改动可在 Diff 编辑器并排审阅；Keep / Reject 仍可用

## 模型配置页（减摩擦）

- [ ] Base URL / API Key / 模型表可在同一入口完成（命令或简易页），减少反复进 Settings
- [ ] Auto + 多模型列表行为与 v0.4 一致

## 明确不做（本版）

- [ ] 无多对话 Tab 条 / Plan·Debug·Multitask 全家桶
- [ ] 无 MCP / 云 Agent / 浏览器工具
- [ ] 无默认无人值守终端（仍遵守 ADR-0002）

## 回归

- [ ] Ask / Agent、多会话、Ghost Text、用户手册、Ctrl+L / Ctrl+I / Esc 仍正常
