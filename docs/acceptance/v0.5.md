## 输入区：图片

- [x] 可将图片拖入 Chat 输入框，显示缩略图 chip，可移除
- [x] Ask / **Agent** 发送后均走多模态 `image_url`（需中转/模型支持视觉，如 glm-4v；纯文本模型应给出可读提示而非原始 JSON）；历史中以 `[图片: name]` 摘要保存
- [x] 超大图片有跳过/提示（约 4MB）

## 输入区：文件 / 文件夹引用

- [x] 可从 OS 拖入文件/文件夹，显示 chip（悬停可见完整路径）
- [x] 从左侧资源管理器 / 编辑器标签拖入：按住 **Shift** 松手可引用；否则用右键 **添加到 Su Chat**、或 Chat 里「当前文件」/ 📎
- [x] OS 拖入无路径时仍可读文本文件为 chip（`fileInline`），不静默丢弃
- [x] 发送时把文件内容（截断）或目录列表注入本轮上下文
- [x] 勾选「选区」仍可用，与附件不冲突

## 输入区：/ Skills

- [x] 输入 `/` 弹出 Skill 列表（工作区 `.cursor/skills`、`.su/skills` + 用户 `~/.cursor/skills`、`~/.cursor/skills-cursor`）
- [x] 方向键 / Enter 可选中；选中后以 chip 附带，发送时注入 system 提示
- [x] 无 Skill 时有明确空态

## 轻量上下文（工作区 / Git）

- [x] Ask / Agent 每轮自动注入：工作区路径、顶层目录、README/ROADMAP 摘录、打开的文件、git 分支；问「总结项目 / 在哪条分支」应基于真实工作区，不再谎称「没权限」
- [x] Ask 可用只读工具 `list_dir` / `read_file` 继续翻项目（不能写文件/终端）

- [x] Agent 执行 `run_terminal` 弹出确认窗；只读 git 可勾选「本会话允许同类 git 只读」
- [x] 需要改文件 / 跑命令时，Ask 应提示切到 Agent（`Ctrl+I`）
