# v0.4 验收清单

验收人：________  日期：________

目标：**Agent 模式**（工作区读写 + 可选确认后终端）+ **改动 Keep/Reject**。沿用中转 / SecretStorage / `su.model`。

## Agent

- [ ] Chat 面板可切换 **Chat / Agent** 模式
- [ ] Agent 模式下发送任务后，模型可调用工具：`list_dir` / `read_file` / `write_file` / `replace_in_file`
- [ ] 工具路径限制在**当前工作区**内（越界拒绝）
- [ ] 写文件后 Chat 中可见工具进度摘要（如 wrote / replaced）
- [ ] `run_terminal`（若启用）每次执行前弹出确认；取消则跳过，不静默跑命令
- [ ] 设置 `su.agent.enableTerminal` 可关闭终端工具
- [ ] 设置 `su.agent.maxSteps` 限制单轮最大工具步数；超限有提示
- [ ] 停止按钮可中断进行中的 Agent 轮次

## Diff 审阅（Keep / Reject）

- [ ] Agent 写入/替换文件后，该文件进入**待审阅**列表
- [ ] 命令 `Su: 审阅 Agent 改动` 可打开待审文件的 Diff（原内容 vs 新内容）
- [ ] **Keep**：确认保留当前磁盘内容，移出待审
- [ ] **Reject**：恢复修改前内容（新建文件则删除），移出待审
- [ ] **Keep All / Reject All** 对全部待审生效
- [ ] 无待审改动时，审阅命令有明确提示
