## Ghost Text

- [ ] 设置中可见 `su.ghostText.enabled`（默认开启）、`su.ghostText.debounceMs`、`su.ghostText.maxTokens`
- [ ] 命令 `Su: 切换 Ghost Text` 可开关行内补全
- [ ] 已配置 Base URL + API Key + Model 后：在编辑器中停顿输入，光标处出现**灰色预览**补全
- [ ] 按 **Tab** 可接受补全并插入文档
- [ ] 继续输入或按 Esc 可取消当前预览（不插入）
- [ ] 关闭 `su.ghostText.enabled`（或切换命令关掉）后，不再请求 / 不再出现预览
- [ ] 防抖：快速连打时不会为每一次按键都打满请求（可用网络面板或中转日志粗看）
- [ ] 未配置 Key 时：不弹错误刷屏，仅静默不补全（Chat 仍可提示设 Key）
- [ ] 补全走与 Chat 相同的 `su.baseUrl` / SecretStorage Key / `su.model`（中转可用）
