# v0.6 验收清单（Agent Window ⇄ IDE Window）

验收人：________  日期：________

目标：自研 Su Agent Window（对话主界面）与经典 IDE Window 双向切换；**不使用**上游 Agents/Sessions / Pitch your idea 壳。

前置：v0.5 功能清单已实现（人工回归可并行）。

## 切换

- [ ] 命令 `Su: 打开 Agent Window（独立窗口）` / `Su: 打开 IDE Window`（或等价 toggle）可用
- [ ] IDE → Agent Window：弹出**独立 OS 窗口**（非 IDE 内编辑器标签）；可继续同一会话
- [ ] Agent Window → IDE：关闭独立窗，回到经典编辑器 + 右侧 Su Chat；会话不丢
- [ ] Chat 顶栏或状态栏有切换入口（不必像素复刻 Cursor 标题栏）
- [ ] ⋯ / 命令可「打开文件夹（新窗口 / 当前窗口）」；无工作区时可纯聊天，空态有打开文件夹入口
- [ ] 顶栏 **+** 新会话不强制绑定新项目（会话空；工作区仍为当前文件夹）

## 功能对等

- [ ] Agent Window 内 Ask/Agent、附件、/ Skills、@、Rules、过程折叠仍可用
- [ ] 写文件 / 终端仍遵 ADR-0002（Diff Keep/Reject；终端在对话区确认：允许一次 / 本会话总是允许 / 拒绝）
- [ ] Agent 执行中对话区可见「处理过程」进度（含等待模型时的「正在思考」与等待秒数）；底部另有实时进度条；工具步骤展开；结束后可折叠查看
- [ ] 生成中禁止再发新任务（提示先停止）；请求超时显示「请求超时」而非「已停止生成」
- [ ] 终端授权卡片置顶可见；进度条显示「等待你授权」；授权等待超过 5 分钟自动跳过，不无限挂起
- [ ] Agent 可用 `ask_user` 对话内反馈卡：抉择关闭=继续不扩展；建议关闭=结束任务；发送后按选择继续；复杂任务允许多次
- [ ] Esc/停止 不会误报「好的，已结束（未执行建议操作）」；应为停止生成
- [ ] 未重新启用微软 `agent-sessions` / MCP Sessions 壳
- [ ] 助手答复 Markdown：`##` 标题醒目；GFM 表格渲染为表格（非原始 `|`）；有序列表 / 代码块可用

## 答复格式

- [ ] Ask/Agent 系统提示要求结构化输出（短结论 + 标题 + 列表/表格）
- [ ] 实质性答复建议保留分区 emoji（如 🔬🗺️⚠️▶️）；结构化优化不得去掉这类图标习惯
- [ ] 问「项目介绍」类问题时，答复分层清晰，对比项优先用表格
