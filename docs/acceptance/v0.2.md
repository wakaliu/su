# v0.2 验收清单

验收人：________  日期：________

目标：**模型/中转配置可用 + Chat 流式主流程**（不做 Ghost Text / Agent Diff）。

## 配置与密钥

- [ ] 命令面板可找到 `Su: AI 配置（中转/模型）`，设置中可见 `su.baseUrl` / `su.model` / `su.timeoutMs`
- [ ] 命令 `Su: 设置 API Key` 可将密钥写入 **SecretStorage**（设置里不再持久化明文 `su.apiKey`）
- [ ] 命令 `Su: 清除 API Key` 可清除已存密钥
- [ ] 若升级前 settings 里仍有明文 `su.apiKey`，启动后会迁移进 SecretStorage 并清空该设置项
- [ ] 未配置 Key 时发起对话，Chat 内有明确提示（并可跳转设置 Key）

## Chat 流式主流程

- [ ] `Ctrl+L`（macOS：`Cmd+L`）打开 / 聚焦侧栏 **Su Chat**
- [ ] 左侧活动栏 **Su AI** 内可见 Chat 面板（输入框 + 发送）
- [ ] 配置正确的 Base URL + Key + Model 后，发送消息可收到 **流式** 回复（逐字/逐段出现）
- [ ] 生成中可 **停止**（abort），停止后不再继续追加
- [ ] 网络错误 / 401 / 超时等在 Chat 内可见可读错误（不静默失败）
- [ ] 可选：勾选「附带当前选区」时，用户消息会带上编辑器选中文本作为上下文
- [ ] 刷新 / 重开侧栏后，**同一工作区**仍可见最近对话（最多约 40 条）；「新对话」可清空
- [ ] 助手回复在流式结束后以 **Markdown** 渲染（代码块 / 粗体 / 列表等）；流式过程中为纯文本
